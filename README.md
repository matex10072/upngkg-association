# UPNG Kundiawa Gembogl Students Association Website

## Run the prototype

Open `index.html` in a modern web browser. The project is fully static and does not need a server for its current prototype features.

## Source files

- `index.html` - home page
- `about.html` - association mission, vision, history, and team placeholder
- `programs.html` - education, welfare, and volunteer-service information
- `events.html` - events, news, and responsive gallery
- `contact.html` - contact information and enquiry form
- `styles.css` - all presentation, desktop/mobile layout, colours, and responsive images
- `script.js` - mobile navigation, dynamic footer year, and prototype contact-form feedback

## Proposal criteria covered

- Responsive, user-friendly multi-page website
- Header, organisation logo, navigation, hero section, motto, main content, footer, social link, and copyright
- Home, About, Programs, Events and Gallery, and Contact pages
- Education, welfare, volunteer-service, events, news, and gallery content
- Contact form with name, email, subject, and message fields
- HTML, CSS, and JavaScript kept in separate files
- Desktop, tablet, and mobile layouts, including a JavaScript-powered mobile menu and responsive gallery images

## Before publishing

Replace the provisional email address, generic Facebook link, unconfirmed phone wording, executive-team placeholder, and event dates with association-approved details. The contact form currently shows a prototype success message; it needs an approved email or form-service connection to send submissions.
